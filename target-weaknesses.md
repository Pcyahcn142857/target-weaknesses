# Target Weaknesses skill
 
## Usage
Use when given problems from a test or competition, such as the SAT or AMC 8.
 
## Instructions
First, find the knowledge points the given problems target and report them to the user. For instance, if it involves the Pythagorean theorem, tell the user it is involves the Pythagorean theorem.
 
Next, create some learning materials for the topic. For instance, if the question tests knowledge on the Pythagorean theorem, create some learning materials about the Pythagorean theorem for review.
 
Finally, If the user states where these problems came from, find more questions on the same topic from that test and give them to the user as further practice. Do not simply tell the user where to find the question; give the user the problem statement and, if present, the options. The answer key should be below all of the questions to prevent spoiling the answers.
